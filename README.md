# Custom Stack Data Structure in Java

## 📌 Project Overview
This project implements a custom **Stack Data Structure** completely from scratch in Java using fixed-size arrays. It demonstrates the fundamental **Last-In, First-Out (LIFO)** principle used extensively in computer science for memory management, function call tracking, and expression evaluation.

## 🚀 Key Features
- **Push Operation:** Adds elements to the top of the stack with built-in `Stack Overflow` protection.
- **Pop Operation:** Removes the top element from the stack with built-in `Stack Underflow` checking.
- **Peek Operation:** Inspects the top element of the stack without removing it.
- **Display Function:** Prints all current elements of the stack in order from top to bottom.

## 🛠️ Technologies Used
- **Language:** Java
- **Concepts:** Object-Oriented Programming (OOP), Arrays, LIFO Principle
